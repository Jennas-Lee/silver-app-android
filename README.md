# 키오스크 시연 화면 (웹)

실버 도우미의 **키오스크 도우미**를 시연할 때 쓰는 버거 매장 주문 화면이에요.
모니터나 태블릿에 띄워 두고, 어르신이 휴대폰 카메라로 이 화면을 비추면서 주문하는 모습을 보여 줄 수 있어요.

가게는 두 곳이에요.

| 주소 | 가게 | 모양 |
|---|---|---|
| `/` | 버거하우스 (버거 매장) | 왼쪽 세로 종류, 노랑·빨강, 단품 / 세트 / 라지 세트 |
| `/chicken/` | 바삭치킨 (치킨 매장) | 위쪽 가로 종류 탭, 빨강·검정, 치킨 조각 수·맛, 버킷, 단품 / 세트 / 박스 |

- 실제 주문이나 결제는 되지 않아요. 가게 이름과 메뉴, 그림은 모두 시연용으로 만든 거예요.
- 두 가게는 같은 화면 코드(`app.js`, `styles.css`)를 쓰고, 가게마다 `menu.js`(메뉴·꾸밈), `art.js`(그림)만 달라요. 치킨 가게는 `chicken/kit.css`로 색과 모양을 덮어써요.
- 이 브랜치(`kiosk-demo`)는 앱 코드와 상관없는 브랜치라서 `main`에 합치지 않아요.

## 들어 있는 것

| 화면 | 내용 |
|---|---|
| 시작 | 매장에서 먹기 / 포장하기, 언어 버튼, 직원 호출 |
| 메뉴 | 왼쪽 종류(추천·버거·아침·사이드·디저트·음료·커피), 메뉴 칸, 품절 표시, 아래 주문 내역 |
| 메뉴 고르기 | 단품 / 세트 / 라지 세트 → 사이드 → 음료 → 수량 확인 (크기·온도 고르기) |
| 주문 완료 | 함께 먹으면 좋은 메뉴 권하기 → 주문 내역 확인 (매장/포장 바꾸기) |
| 결제 | 카드, 간편 결제(바코드), 모바일 상품권(12자리), 현금(카운터 안내) |
| 끝 | 결제 중 → 카드 빼기 → 영수증 출력 여부 → 주문 번호 → 20초 뒤 처음으로 |

카드 투입구와 바코드 스캐너 그림을 누르면 카드를 꽂거나 바코드를 댄 것으로 처리해요.
3분 동안 아무것도 누르지 않으면 "주문을 계속하시겠어요?" 창이 뜨고, 30초 뒤 처음 화면으로 돌아가요.

## 주소 옵션

| 옵션 | 뜻 |
|---|---|
| `?idle=0` | 오래 안 누르면 처음으로 돌아가는 기능 끄기 (`?idle=300` 처럼 초 단위로 바꿀 수도 있어요) |
| `?screen=menu&cat=burger` | 바로 그 화면 열기 (`menu`, `review`, `pay`, `card`, `simple`, `gift`, `number`) |
| `?item=big` | 그 메뉴의 고르기 창 열기 |

## 띄우는 법

빌드가 필요 없는 정적 파일(HTML, CSS, JS)이에요.

```bash
# 내 컴퓨터에서
python -m http.server 8000   # → http://localhost:8000
```

GitHub Pages: 저장소 Settings → Pages → Source를 **Deploy from a branch**, Branch를 `kiosk-demo` / `/ (root)`로 고르면 돼요.
(비공개 저장소는 GitHub 유료 요금제에서만 Pages를 쓸 수 있어요.)

화면은 세로 1080×1920 키오스크 크기로 만들었고, 창 크기에 맞춰 저절로 줄어들어요. 세로로 세운 모니터나 태블릿에서 전체 화면(F11)으로 띄우면 가장 비슷해요.
